Code-based factors

Authenticator app

Start with TOTP
TOTP uses time: your app shows a new six-digit code every 30 seconds.HOTP uses a counter: the app advances it each time it generates a code, and the server checks the next unused value.Both use an authenticator app, but HOTP needs an app that explicitly supports it.
